# 💖 宝宝我们和好吧 — Apologize

> **道歉互动网页 · 用可爱的方式说和好**  
> 一个充满趣味交互的「求原谅」表白小页面。

> 🚀 **在线演示：** [https://xkj666.netlify.app](https://xkj666.netlify.app)

---

## 📖 项目简介

一个甜蜜又有趣的互动网页——点击「❤️和好❤️」接受道歉，点击「不要」按钮会触发一系列可爱的交互反馈：爱心图片变化、和好按钮持续放大、按钮文字逐次变化。适合用来哄对象开心 💕

---

## ✨ 交互效果

| 操作 | 反馈 |
|------|------|
| ❤️ **和好** | 爱心放大 → 弹出甜蜜提示「我们永远在一起吧」 |
| 😅 **不要** × 1 | 按钮文字变为「真的不要」，爱心图片切换 |
| 😅 **不要** × 2 | 按钮文字变为「再考虑一下」 |
| 😅 **不要** × 3 | 按钮文字变为「求求你啦」，特殊爱心图 |
| 😅 **不要** × 4 | 按钮文字变为「最后一次机会」 |
| 😅 **不要** × 5 | 弹出委屈提示「你就那么不想和我和好吗」，自动重置 |
