## 📖 项目简介

把对象惹生气了怎么办？🤔 掏出这个自制小网页，虔诚地发给 ta——

> 点「❤️和好❤️」万事大吉，点「不要」的话……  
> 建议你不要一直点「不要」，后果自负（手动狗头）🐶

主打一个 **态度到位了，剩下的交给代码** 💕

---

## ✨ 交互效果

| 操作 | 反馈 |
|------|------|
| ❤️ **和好** | 爱心放大 → 弹出甜蜜提示「我们永远在一起吧」 |
| 😅 **不要** × 1 | 按钮文字变为「真的不要」，爱心图片切换 |
| 😅 **不要** × 2 | 按钮文字变为「再考虑一下」 |
| 😅 **不要** × 3 | 按钮文字变为「求求你啦」，特殊爱心图 |
| 😅 **不要** × 4 | 按钮文字变为「最后一次机会」 |
| 😅 **不要** × 5 | 弹出委屈提示「你就那么不想和我和好吗」，自动重置 |
